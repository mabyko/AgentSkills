- 입력: [실제로 제공한 요청 전문](final-requests.md), 당시 최종 스킬 폴더의 임시 사본.

생성 세션에는 판정 기준, 이전 출력, 리뷰 지적을 주지 않았다. 세 요청은 한 생성 세션에서 처리했다. 단, 생성자가 슬래시 호출로 이전 전역 설치본도 자동 로드됐다고 보고했다. 지정한 임시 사본을 기준으로 작성했지만, 수정본만 노출된 실험은 아니다. 이전 버전을 따로 실행하지 않았고 독자 이해도도 측정하지 않았다.

## C2 — 복원 정책

출력: [policy.final.ko.md](policy.final.ko.md)

한국어로 일반 복원의 두 조건(14일 미만과 소유자 승인)을 함께 제시했다. 정확히 14일인 사례를 일반 복원에서 제외했고, 서비스 책임이 팀에 의해 확인된 예외에도 승인을 요구했다. 예외에서는 최신의 손상되지 않은 스냅샷을 복원한다는 약속을 유지했다.

다운로드와 복원, 달력 날짜와 영업일, 응답과 복원 완료, 통상 2영업일과 비보장을 구별했다. 정책에 나오지 않은 절차와 기준 시점을 따로 밝히되 새로운 정책을 만들지 않았다.

판정: C2의 의미 보존 기준을 충족했다.

## C5 — 흩어진 작업 기록

출력: [status.final.ko.md](status.final.ko.md)

현재 상태와 효과 미확인을 먼저 제시하고, 수행 주체·수집 일정·관측 위치를 찾아볼 수 있게 묶었다. 46개에서 58개로 확대, 기존 46개 유지, 10월 24일 07:00 시작, 기준선의 의미, JSON에만 순위를 기록한다는 조건을 보존했다. 10월 29일의 중간 비교와 11월 12일의 최종 판정 예정을 구별했다.

오타 수정과 시험 호출을 특정 담당자의 일로 넣지 않고 표에서 수행자가 기록되지 않았다고 표시했다. 시험 호출 1건과 문서 완료 표시를 전체 수집·검색 노출 효과의 검증으로 확대하지 않았다. 시작 일정과 실제 실행 여부도 구별했다. 사용자에게 새 과제를 만들지 않았다.

판정: 보강된 C5 기준을 충족했다. 최초 응답의 잘못된 책임 귀속은 이 출력에서 반복되지 않았다. C5는 원문 첨부를 변형한 사례이므로 다른 분야로 일반화할 근거는 아니다.

## C6 — 캐시의 시간과 요청

출력: [cache.final.ko.md](cache.final.ko.md)

요청 발생과 경과 시간이라는 두 조건을 함께 설명했다. 09:00 저장 뒤 09:10까지 요청이 없었던 실제 상황과, 각 시점에 요청이 있었다면 일어날 일을 구분했다. 299초의 재사용과 정확히 300초의 재조회 경계를 보존했다. 09:10 요청 유무를 비교해 기다림만으로 조회가 일어나지 않는 이유를 드러냈다.

재조회와 값 자체의 변화도 구별했다. 불필요한 역할별 보고나 사용자 과제를 붙이지 않았고, 요청한 한국어 글로 마쳤다.

판정: C6 기준을 충족했다. 표와 규칙·비유 사이에 내용 반복이 있어, 분량과 읽기 부담이 줄었다는 근거로는 사용하지 않는다.

## 범위와 남은 한계

세 출력은 판정 기준을 주지 않은 별도 세션에서 생성했고, 작성자가 의미와 구성을 대조했다. 세 사례의 기준을 충족했다는 결과이며, 모든 주제에서의 품질이나 이전 버전 대비 향상을 보증하지 않는다. 이전 스킬 자동 로드의 영향도 분리하지 못했다.

생성자는 UTF-8 읽기와 Markdown 표의 열 개수를 확인했다고 보고했다. 작성자는 보존 파일의 UTF-8 읽기, 원본 출력과의 바이트 일치, 스킬 해시 일치를 확인했다. Markdown 표의 화면 렌더링, HTML·영상 제작, C1·C3·C4, 실제 독자 이해도는 이번 실행에서 검사하지 않았다.

## 참고 저장소와 비교한 변경

[ste-business-writing의 SKILL.md](https://github.com/ninajingit/ste-business-writing/blob/main/SKILL.md)를 읽고 비교했다. 결론 우선, 직접적인 동사, 용어 통일, 수치·조건 보존은 기존 지침과 구성 보강에 이미 있다. 문구만 수정할 때 명확한 문장은 유지하고, 의미·조건·말투를 바꾸지 않는 범위에서 군더더기를 줄인다는 지침을 언어 참조에 추가했다. 이 문장도 위 해시에 포함된다.

한국어에 고정 단어 수나 무조건적인 능동문을 적용하지 않고, 기존 의미 보존과 자연스러운 한국어 지침을 유지했다. 이 비교는 해당 스킬의 정식 STE 준수나 효과를 검증한 결과가 아니다.
