# 캐시는 언제 다시 조회할까?

60초 분량을 목표로 한 한국어 영상 대본입니다. 아래 구간은 낭독 전 추정이며, 실제 길이는 읽는 속도와 쉼에 따라 달라집니다.

**0–10초**

같은 질문을 받을 때마다 답을 새로 구하면 시간이 걸리겠죠? 캐시는 한 번 구한 답을 잠시 저장해 두고 다시 쓰는 방법입니다.

**10–20초**

지금 보는 가상 모델에서는 처음 조회한 결과와 조회한 시각을 함께 저장합니다. 모든 시간은 하나의 시계로 잽니다.

**20–30초**

다음 요청이 오면, 저장한 뒤 얼마나 지났는지 확인합니다. 아직 300초가 되지 않았다면 저장된 결과를 그대로 씁니다.

**30–40초**

정확히 300초가 됐거나 그보다 오래 지났다면, 그 요청에서 원본을 다시 조회합니다. 새 결과를 저장하면서 시각도 바꿉니다.

**40–50초**

그런데 아무도 요청하지 않으면 어떨까요? 300초가 지나도 다시 조회하지 않습니다. 다음 요청이 와야 시간을 비교하죠.

**50–60초**

정리해 볼까요? 요청이 왔을 때 300초 미만이면 재사용하고, 300초 이상이면 다시 조회합니다. 시간이 지났다는 것만으로 조회가 시작되지는 않습니다.
