## 지침 변경 전후 대조

- **설명 목표:** 이전에는 매체별 이해상의 이점을 탐색하도록 했다. 이제 독자가 무엇을 이해·예측·판단할 수 있어야 하는지 먼저 정하고, 결과가 그 판단에 필요한 정보를 주는지 확인한다.
- **요청한 단계:** 이전에는 영상의 렌더링·재생 확인을 강조했다. 이제 대본·스토리보드·소스·완성본·부분 수정의 완료 기준을 구분한다. 영상 가이드도 장면 계획과 렌더링을 나눴다.
- **문서 로딩:** 특정 외부 렌더러의 언어 제약과 사용법을 매체 가이드에서 조건부 참고 문서로 옮겼다. 자동 호출과 복합 매체를 선택할 수 있는 기본 방침은 유지했다.

위 항목은 지침 대조 결과다. 이전 지침에서 실제 과잉 제작이 발생했다는 재현 기록은 아니다.

## C1 — 대본만 요청

산출물: [script.ko.md](script.ko.md)

- 300초 미만의 재사용, 300초 이상의 요청 시 재조회, 요청이 없을 때의 동작, 같은 시계라는 가정을 원자료와 대조했다.
- 구간 시간을 낭독 전 추정으로 표시했다. 음성·영상 파일은 제작하지 않았고 실제 낭독 시간도 측정하지 않았다.
- 결과를 요청한 대본 단계의 완료물로 취급했다.

판정: 작성자 검토에서 요청 범위와 모델의 조건을 보존했다. 이 기록은 렌더링 품질 검증이 아니다.

## C2 — 영어 정책의 한국어 설명

산출물: [첫 초안](policy.ko.md), [경계 표현 수정본](policy.ko.revised.md)

첫 초안은 일반 복원의 두 조건, 서비스 책임이 확인된 경우의 예외, 예외에도 필요한 승인, 최신의 손상되지 않은 스냅샷, 다운로드와 복원의 구별, 답변 시간의 비보장을 담았다.

검토 중 첫 초안의 “14일째부터”가 날짜를 세는 방식에 따라 다르게 읽힐 수 있음을 발견했다. 수정본에서는 “만들어진 지 정확히 14일이 된 스냅샷부터”로 풀었다. 두 결과를 모두 남겼으며, 수정본은 같은 작성자의 교정이지 별도 독립 실행이 아니다. 사례의 판정 기준도 같은 경계를 명확히 표현하도록 다듬었다.

판정: 경계 표현을 교정한 뒤 작성자 원문 대조에서 의미 보존을 확인했다. 새로운 사실을 추가하거나 보통 2영업일이라는 응답 시간을 복원 완료 보장으로 바꾸지 않았다.

## C3 — 웹의 한 문장만 수정

입력: [cache.html](../../fixtures/cache.html) · 산출물: [수정한 cache.html](cache.html)

바이트 대조로 지정한 한 문장만 바뀌고 스타일·스크립트·초기값을 포함한 나머지 내용이 그대로임을 확인했다. 수정 파일을 T3 브라우저에서 열고 입력 도구와 초기화 버튼으로 다음 상태를 확인했다.

- 초기값 TTL 300 / 경과 120: 저장된 결과 사용
- TTL 300 / 경과 299: 저장된 결과 사용
- TTL 300 / 경과 300: 원본 재조회
- TTL 300 / 경과 301: 원본 재조회
- TTL 600 / 경과 301: 저장된 결과 사용
- 초기화: TTL 300 / 경과 120, 저장된 결과 사용으로 복원

판정: 요청한 변경 범위와 기존 조작을 확인했다. 이 실행에서 모바일 배치·전체 접근성·모든 잘못된 입력을 추가 검사하지는 않았다.
